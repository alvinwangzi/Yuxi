# 市场技能快照文件发布与工作流查询归属

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/skills/personal.py

## 问题

市场安装只更新数据库索引时，个人技能缺少实际文件。内置快照遗漏嵌套资源；工作流可选查询迁入 repository 后遗漏部门可见性。

## 决策

### 实现方案

市场 service 调用个人技能文件 Owner 发布快照。Owner 校验全部相对路径，在临时目录完成写入后交换目录；事务提交清理备份，回滚恢复原目录。市场条目行锁串行化同条目的安装更新。package Owner 递归读取 UTF-8 文本资源，保留脚本和模板相对路径。

个人文件 Owner 也拥有市场提交快照的读取，公开接口只返回文本内容。扫描器覆盖所有待分发文本，嵌套 Python 文件沿用既有 AST 检测，文件位于其他目录不能绕过扫描。

Agent 自动创建、工作流统计与可选列表由对应 repository 持有查询。可选列表沿用既有可见性条件，并排除平台流程。Agent 分类过滤与角色导入分类映射保持调用方语义。

## 替代方案

拒绝在市场 service 直接获得用户宿主路径；拒绝删除原目录后才校验快照。未引入跨数据库和文件系统的持久发布状态机。

## 后果

普通事务失败可以恢复文件；进程崩溃、磁盘清理失败及绕过市场入口的并发文件写入仍不具备跨资源原子性保证。文本快照跳过二进制文件，不能宣称完整二进制包分发。未执行批量历史技能修复或重建已有市场条目。

## 验证

个人技能 unit 覆盖物化、更新、越界路径和无效更新保留旧文件；文本快照 unit 回读嵌套脚本与模板。真实 PostgreSQL integration 回读提交和回滚后的文件，并断言部门工作流可选范围。Agent repository 相关 unit 验证既有行为。
