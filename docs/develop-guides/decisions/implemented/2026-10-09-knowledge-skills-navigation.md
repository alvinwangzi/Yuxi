# 知识库与技能连接器导航收敛

状态：implemented
类型：bug-fix
Owner：web/src/router/index.js

## 问题

知识库菜单进入包含 MCP、工具、技能和连接器的旧扩展聚合页；技能连接器又有重复内容，Agent 的 MCP 配置回到旧入口，页面标题、菜单选中和资源归属不一致。

## 决策

### 实现方案

知识库列表、详情和评估由 `/knowledge` 独立页面拥有；技能、工具、MCP、渠道和业务连接器统一由 `/skills` 页面拥有。连接器作为管理员 Tab，保持现有权限。菜单、Agent 配置及详情返回链接直接使用统一地址。旧 `/extensions` 列表和知识详情地址仅重定向，保留资源、非 tab 查询和 hash，不再渲染第二份聚合界面。

## 替代方案

只修改菜单文字会留下重复界面和错误深链接；直接删除旧 URL 会破坏用户书签与已分享详情。采用单一页面加旧地址重定向。

## 验证

| 验收主张 | 失败面 | 语义 Owner | 直接证据 / 命令 | 负向案例 | 当前结果 |
| --- | --- | --- | --- | --- | --- |
| 知识库菜单只有知识能力 | 旧扩展页面仍显示连接器 | router / KnowledgeView / AppLayout | 浏览器菜单点击与 DOM | 原页面可见多个资源 Tab | Passed |
| 连接器/MCP/技能只有统一入口 | 重复页与旧地址仍渲染 | SkillsConnectorsView / legacy redirect | 单元路由与浏览器 URL/DOM | 旧 URL 未重定向 | Passed |
| Agent MCP 配置进入统一 MCP | 编辑弹窗仍指向扩展页 | AgentEditModal | 浏览器配置按钮点击 | 原按钮进入 `/extensions` | Passed |

## 后果

知识库详情和评估深链接必须保留参数与权限；不修改后端授权、资源数据、菜单命名或工作流功能。只在 dev 当前工作区修改，保留无关未提交工作。

实际验证：14 项路由与知识相关回归通过；浏览器确认知识库菜单、连接器 Tab、旧连接器 URL 和实际 Agent MCP 配置按钮跳转。只读知识库详情没有强行打开，详情/评估参数与管理守卫由实际 Vue Router 单元验证。Web 全套 413 passed / 10 个既有失败，lint 保留 20 个既有错误，构建通过；完整结果不报全绿。
