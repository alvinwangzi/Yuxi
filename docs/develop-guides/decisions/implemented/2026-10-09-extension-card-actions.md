# 渠道和连接器卡片操作收敛

状态：implemented
类型：bug-fix
Owner：web/src/components/extensions/ConnectorCardList.vue

## 问题

卡片直接暴露删除按钮容易误触；渠道 mini 卡片不渲染 tags 插槽，因此其启用状态不可见。

## 决策

### 实现方案

两类删除入口位于 InfoCard 既有更多菜单，确认弹窗之后才执行原删除接口。渠道在 mini 卡片 action 插槽显示已开启或已关闭，以后端 enabled 为准，不将启用配置等同于运行健康。

连接器在 action 插槽提供启停开关，通过既有 API PATCH 提交 enabled 与 expected_revision，后端继续拥有授权、凭据和配置校验。请求期间锁定启停和删除入口；成功采用后端状态与版本，失败提示并回读列表，不假定本地状态已保存。

## 替代方案

拒绝卡片直接删除；不增加独立启停接口或绕开既有后端校验。

## 后果

删除多一个明确确认步骤。开启不完整的连接器仍会被后端拒绝。渠道状态表示启用配置，运行健康继续由既有渠道机制拥有。

## 验证

浏览器验证两类菜单与取消删除、渠道状态和连接器开关呈现。卡片实际处理函数 unit 验证版本提交、服务器确认后更新、重复操作阻止和失败回读；不通过改变真实测试连接器状态执行负向案例。
