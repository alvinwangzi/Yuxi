# 开发路线图

这里记录尚未完成的方向，不代表已经实现或一定会在某个版本发布。需求和优先级会根据 Issue、讨论和维护资源调整；欢迎在 [GitHub Issues](https://github.com/xerrors/Yuxi/issues) 提交建议。

## 计划中的不兼容方向

后续 0.8 版本可能包含：

- 升级 Milvus 3.0；
- 进一步解除 API/worker 对共享文件系统的依赖，支持更清晰的分布式部署边界。

这两项会影响部署和数据迁移，确定方案前会单独说明升级条件和兼容范围。

## 知识库

- 为知识导图增加基于文件名的关联边，并探索用聚类形成社区节点。
- 增加按关键词排序的 `query_keywords` 工具。
- 丰富检索结果中的 metadata 和标签。
- 为个人工作区增加检索能力，但不做向量化。

## 智能体

- 为子智能体增加 Steer 机制。
- 增加子智能体向主智能体提问的 `ask_for_main_agent` 能力。
- 设计子智能体之间的通信机制。
- **Agent 自进化体系**：对话后自动回顾提取经验、质量守门过滤低质量沉淀、定期整理合并重复经验。详见[决策记录](./decisions/proposed/2026-09-12-agent-self-evolution-system.md)。

## 连接器：完善 CRM 关联表能力

下一阶段优先继续完善连接器相关功能。2026-10-09 的飞书 CRM 基础测试仅连接了客户表和商机表，尚未覆盖客户联系人、合同及跟进信息等相关表，不代表完整 CRM 业务链路已完成。

- 梳理实际 CRM 中的客户联系人、合同、跟进记录及其他相关表，确认字段类型和表间关联，避免仅依靠固定的客户表、商机表配置。
- 扩展表目录选择、字段映射和自动参数命名，使需要接入的关联表可配置；具体操作范围在开发前确认。
- 支持围绕客户或商机查询关联联系人、合同和跟进信息，保留明确的表、记录身份与访问范围。
- 分阶段验证读取及确有需要的写入操作；写入继续遵循授权、审批和结果回读，不将查询通过视为写入验收。
- 用真实关联表完成配置、Agent 调用和结果核对，并同步更新连接器页面的配置引导。

开始实现前确认各表的实际结构、优先业务场景和验收用例；本项记录开发方向，不承诺所有表均支持通用 CRUD、自动同步或某一版本的交付日期。
